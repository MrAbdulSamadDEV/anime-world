# Anime World

Build a polished, production-quality responsive 3D anime/creative website named ANIME WORLD. Visual direction: original cinematic anime-inspired world, deep midnight navy/black background, electric cyan and violet highlights, luminous gradients, premium editorial typography, subtle particles, layered depth, smooth scroll and tasteful micro-interactions. Do not copy any copyrighted anime characters, logos, screenshots, or assets; use original abstract/fantasy visuals and CSS-generated effects or properly licensed assets. Build a compelling homepage with: sticky responsive navigation, hero with clear ANIME WORLD branding and CTA, featured original fantasy/anime worlds or character cards, an explore/discover section, a short about section, contact section with accessible form validation and honest success/error feedback (no fake backend submission; if no backend exists, use mailto or clearly mark demo), and footer with social placeholders that are easy to replace. Add responsive mobile menu, reduced-motion support, semantic HTML, keyboard accessibility, useful SEO title/meta description/Open Graph basics, optimized images/lazy loading, fast loading and good contrast. Use the project's default TypeScript/Tailwind stack and existing dependencies where possible; avoid unnecessary heavy 3D libraries if a CSS depth effect can deliver the visual quality. Ensure there are no dead buttons or misleading functionality. Implement the actual site now, then run available checks/build, fix errors, and summarize any limitations. Do not publish or connect to GitHub without checking/confirming integration requirements first.
